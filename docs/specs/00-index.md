## 未解决问题

任何产品决策如果未在规格中定义，不能由 Codex 自行发明。应新增 ADR 到 `18-decisions.md`。

## V1 明确不追求

- 无限通用的自然语言
- 完全自动的高风险业务
- 所有行业一次性做全
- 所有电子秤一次性兼容
- 无服务器的官方支付自动确认

## V1 必须做到

- 完整离线营业闭环
- AI 可操作核心业务
- 业务数据不会因为 AI/网络失败而损坏
- 可解释、可审计、可重建
- 菜店和五金店共用一套底层模型
