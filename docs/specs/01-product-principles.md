# 产品原则与 V1 范围

## 1. 用户模型

主要用户：1~3 人的小店老板/店员，可能不会熟练打字、不愿学习复杂软件、已有 Android 手机。

典型行业：
- 菜店/水果/农产品
- 五金/水电材料
- 便利店/小卖部
- 日杂/土特产

## 2. 一条主线

老板说“发生了什么”，系统把它转成可靠的店铺事实。

## 3. V1 五个高频循环

### 循环 A：采购
扫码/语音 → 商品 → 数量 → 成本 → 入库 → 成本更新

### 循环 B：销售
扫码/语音/点选 → 当前订单 → 计算 → 收款 → 扣库存

### 循环 C：会员
找会员 → 充值/消费 → 余额流水 → 查询

### 循环 D：客户赊账
找客户 → 销售 → 欠款 → 后续收款

### 循环 E：经营查询
“今天卖多少？”、“缺什么？”、“什么卖得最好？”

## 4. 关键指标

- 首次建店 ≤ 5 分钟
- 常见条码商品销售 ≤ 10 秒
- 简单语音销售一步完成
- 关键业务 100% 可离线
- 每个账务动作可追溯

## 5. V1 业务范围补强

与旧版本相比，本版新增并明确：
- 出货/履约状态：销售与“交付/提货/送货”解耦
- 日结/班次：可选的现金与支付方式对账
- 数据导出/备份/恢复
- 数据迁移与 schema version
- 幂等键与重复提交保护
- 统计口径定义
- AI 评测集和回归门槛
- 配置/功能开关
