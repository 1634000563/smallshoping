# 报表口径

## 1. 销售额

已完成销售订单的有效销售金额，扣除已确认退款影响。

## 2. 商品成本

按 sale_item 中的成本快照计算；V1 默认采用加权平均成本作为入库成本基准。

## 3. 经营毛利

`销售净额 - 商品成本`

不等于会计净利润。

## 4. 损耗

单独展示，不伪装成销售。

## 5. 会员充值

充值是资金流入/客户预存，不应直接计入商品销售额。

## 6. 会员消费

消费进入销售额；付款方式为 MEMBER_BALANCE。

## 7. 客户赊账

销售额按销售确认；支付尚未完成，形成 customer receivable。

## 8. 日结

比较“系统应收现金”与“老板实际点到现金”，记录差异，但不修改历史销售。
