# 数据迁移、导入与导出

## 1. 为什么 V1 必须有

目标用户可能来自纸张、Excel 或旧进销存系统。没有迁移能力，切换成本会直接阻断获客。

## 2. V1 导入

至少支持 CSV：
- 商品
- 条码
- 售价
- 成本
- 单位
- 初始库存
- 会员
- 客户

未来再支持 XLSX/旧软件格式。

## 3. 导入流程

```text
选择文件
↓
解析
↓
预览
↓
字段映射
↓
重复项检查
↓
错误行报告
↓
用户确认
↓
事务导入
```

禁止“导入一半失败但用户不知道”。

## 4. 导出

V1 至少支持：
- 商品
- 当前库存
- 销售明细
- 会员流水
- 客户欠款
- 采购

## 5. 备份

导出备份必须包含 schema_version、store_id、export_time、checksum。
恢复前先验证版本和 checksum。
