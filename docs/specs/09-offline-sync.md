# Offline First 与未来同步

## 1. Offline Contract

完全无网络时，以下必须工作：
- 商品
- 扫码
- 销售
- 采购
- 库存
- 称重计算
- 会员
- 客户欠款
- 现金收款
- 微信/支付宝手工确认记录
- 日报/月报

## 2. 网络只是增强

网络负责：
- 云 AI
- 备份
- 恢复
- 未来多设备同步
- 未来官方支付状态查询

## 3. 本地优先写入

业务先写本地事务，不等待云端。

## 4. Outbox 预留

V1 可以建立 `outbox_event` 抽象但默认关闭远程同步。
事件只描述“业务事实已发生”，不复制整个 DB。

## 5. 未来同步冲突

- Ledger 事件不可改写
- 配置类数据采用 last-write-wins 或用户确认
- 商品价格变化需要版本号/时间戳
- 多设备同时销售需要设备 ID + event ID + idempotency

## 6. 数据备份

V1 必须至少提供：
- 本地数据库备份导出
- 导入恢复
- 恢复前校验
- 数据版本号

恢复不是覆盖式盲写；先校验 schema/version/checksum，再替换或迁移。
