# UI/UX

## 1. UI 不是主入口

优先：语音、扫码、快速点击。

## 2. 首页

```text
今天
销售 ￥1,286
86笔

[扫一扫] [加商品]

🎤 说一说

库存预警 3
会员待处理 2
```

## 3. 收银

当前订单优先显示，不强迫用户进入多级菜单。

支持：
- 条码
- 商品快速选择
- 重量输入
- 语音添加

## 4. 反馈

每次 AI 写操作应让老板知道：
- 做了什么
- 金额/数量
- 是否完成
- 如果未完成，卡在哪里

但不应要求低风险操作层层点击。

## 5. 传统页面

保留：商品、采购、库存、会员、客户、报表、设置。

这些是“检查/纠错/高级管理”入口，不是日常主路径。

## 6. 语音 UX

必须允许老板中断、修改和撤销当前草稿。

例如：
“土豆两斤六。”
→ “土豆2.6斤，9.88元，已加入。”

如果老板说：
“不是土豆，是红薯。”
→ 修改当前草稿，不创建错误交易。
