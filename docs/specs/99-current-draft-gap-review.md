# 对上一版规格书的最终审查

## A. 原版已经正确的部分
- AI-first
- Domain / Tool / Ledger / SQLite 分层
- 离线优先
- 菜店/五金通用 Product 模型
- 语音、扫码、称重
- 会员/客户/支付
- 风险与状态机
- Codex 分阶段开发

## B. 原版不足、已补齐
1. 出货/Fulfillment 与销售解耦
2. 日结/经营核对
3. 幂等与重复提交
4. 崩溃恢复与 Ledger 重建
5. schema migration / backup / restore
6. store_id / device_id 预留
7. AI Gateway 与客户端密钥安全
8. Tool/Prompt/Model 版本化
9. AI 黄金集和危险动作发布门槛
10. CSV 导入/导出，降低迁移成本
11. 经营毛利与净利润概念分离
12. 业务日期/timezone
13. 负库存策略
14. Feature flags 与运维诊断
15. 更完整的销售/出货 Tool 清单

## C. 当前仍属于 V1 之后
- 官方微信/支付宝自动回调闭环
- 全品牌蓝牙/串口秤
- 多设备实时冲突解决的完整实现
- 多店实时经营
- 云端全量业务数据库
- 法定会计

## D. 完成度判断

本规格包已经达到“可让 Codex 按阶段实施”的级别，但不等于“无需人验收即可商业发布”。真实设备、支付商户、模型服务、语音环境和真实门店流程仍必须做实测。
