# V1 验收标准

## P0 黄金路径

### 路径 A：菜店

老板：
“进100斤土豆，2块8，卖3块8。”

结果：
- 商品存在/建立
- 库存 +100斤
- 成本 2.8
- 售价 3.8

老板：
“卖两斤六。”

结果：
- 当前订单加入2.6斤
- 金额9.88

老板：
“微信。”

结果：
- 付款方式=WECHAT_MANUAL
- 老板确认后销售完成
- 库存变97.4斤

老板：
“今天卖了多少钱？”

结果：本地计算回答。

### 路径 B：五金店

“304 M8x30螺丝一盒100个，盒子20块；客户要8个。”

结果：单位换算正确、按单个价格计算、库存正确。

### 路径 C：会员

“张姐充200。”

如果唯一 → 充值。
如果多个 → 消歧。

### 路径 D：客户赊账

“老张先记账。”
→ sale complete + customer ledger 增加应收。

## P0 可靠性

- 无网络完整运行

- 重复提交不重复扣库存
- 崩溃恢复账本一致
- 会员余额可重建
- 库存可重建
