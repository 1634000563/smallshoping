# V1 AI 原生小店操作系统 — Codex 难点优先开发包

## 一句话

**老板不学软件，软件学老板。**

本版本不是传统进销存“先做完整、最后加 AI”，而是采用：

> **最难问题先验证 + AI 原生 Vertical Slice + 确定性 Domain/Ledger 承载事实。**

## 开始方式

1. 让 Codex 读取根目录 `AGENTS.md`。
2. 再读取 `plans/V1_IMPLEMENTATION_PLAN.md`。
3. 再读取 `plans/V1_CODEX_TASK_MANIFEST.md`。
4. 只执行当前 Task，不跳任务。
5. Task 完成后必须通过测试与 Guard，再进入下一个。

## 第一个真正产品里程碑

不要等待传统“商品、采购、销售、报表”全部完成。

第一个核心里程碑是：

> 用户说“卖两斤土豆” → 系统理解 → 找到土豆 → 查价格 → 形成销售动作 → 扣库存 → 写 Ledger → 返回结果。

然后验证：

> “今天卖了多少钱？”

如果这两条失败，应优先修复 AI/上下文/Tool/Domain/账本架构，而不是继续堆页面。
